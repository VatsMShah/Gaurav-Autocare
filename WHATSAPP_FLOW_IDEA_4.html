⛽ WhatsApp Native Flow (Idea 4) Specification

Interactive Fuel Truck Ordering with Dynamic Bidirectional Calculation

1. Executive Summary

Idea 4 provides an interactive WhatsApp Native Flow Form for Gaurav Autocare's Fuel Truck ordering bot. Instead of typing lengthy paragraphs or getting stuck in back-and-forth chat loops, customers tap a single button inside WhatsApp that opens a smooth, native popup form directly on their screen.

Core Benefits:
  • Zero App Download: Operates 100% within WhatsApp (Android, iOS, Web).
  • Single Screen Submission: Vehicle number, fuel type, quantity, or budget filled in under 15 seconds.
  • Flexible Bidirectional Calculation: Users can enter either Litres OR Budget Amount (₹) — the system dynamically calculates the matching value.
  • Instant Verified Ticket: Saves order to Supabase and dispatches official digital ticket #GA-XXXXXX.

2. Form UI & Field Architecture

Field Name Component Type Requirement Description & Validation
Vehicle Number TextInput Required Accepts vehicle plate number (e.g. MH04XZ1212, MH05678). Auto-capitalized.
Fuel Type RadioButtonsGroup Required Options: Diesel (HSD) @ ₹92.80/L or Petrol (MS) @ ₹104.50/L.
Quantity (Litres) TextInput (number) Optional Enter required volume (e.g. 500, 1000). Optional if budget amount is entered.
Budget Amount (₹) TextInput (number) Optional Enter order budget in INR (e.g. ₹50,000). Optional if litres is entered.

3. Smart Auto-Calculation Formulas

The system uses current published pump rates (Diesel: ₹92.80/L | Petrol: ₹104.50/L):

  • If user specifies Litres (L):
    Estimated Amount = round(Litres × Rate)
    Example: 1,000 Litres Diesel = ₹92,800
  • If user specifies Amount (A):
    Litres = round(Amount ÷ Rate)
    Example: ₹50,000 Diesel = 539 Litres
